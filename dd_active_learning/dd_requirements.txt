# =============================================================================

# Targets the Digital Research Alliance of Canada / "+computecanada" wheels).
#
#   tensorflow==2.15.*  -> newest TF that still defaults to Keras 2 (tf.keras),
#                          which the DD training code uses. 2.16+ = Keras 3 and

#   numpy<2             -> TF 2.15 needs numpy >=1.23.5,<2.  These numpys no
#                          longer have np.bool (removed in 1.24). The wizard
#                          installs a startup shim (sitecustomize) that restores
#                          np.bool / np.int / ... so the unmodified DD code runs.
#
# CUDA is provided by the cuda module already loaded for the docking engine
# (gnina / AutoDock-GPU). no tensorflow[and-cuda] here.
#
# Meeko is installed separately by the wizard (usually not in the wheelhouse,
# so it comes from PyPI).  Do not add it here.
#
# Check availability first:  avail_wheels numpy pandas scipy scikit-learn \
#     matplotlib "tensorflow==2.15.*" rdkit
# =============================================================================
numpy<2
pandas
scipy
matplotlib
scikit-learn
pyyaml
tqdm
tensorflow==2.15.*
